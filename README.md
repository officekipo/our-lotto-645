-   `추천 결과` → `생성 결과`, `추천받기` → `생성하기`, `추천 설정` →
    `생성 설정`
-   번호 생성 페이지에 `내 번호` 저장 기능 추가
-   `필수 번호 저장` / `필수 불러오기` 추가
-   `제외 번호 저장` / `제외 불러오기` 추가
-   저장 데이터는 기기 로컬 저장소에 유지
-   생성 결과별 `내 번호로 저장` 지원
-   저장된 내 번호 최대 30개 관리
-   최근 10·30·50·100·300·500·1000회 통계 기반 생성 조건 추가
-   직접 회차 입력(10\~1000회) 지원
-   많이 나온 번호 중심 생성
-   가장 적게 나온 번호 중심 생성
-   평균 출현 빈도에 가까운 번호 생성
-   가장 많이 나온 홀/짝 패턴을 반영한 생성
-   기존 필수/제외 번호 조건과 모든 생성 전략을 함께 적용
-   기존 랜덤 생성은 `기본 생성`으로 유지
-   기존 API/당첨 확인/통계/세후 계산 기능은 유지

## 통계 생성 기준

정확히 동일한 6개 번호 조합의 과거 출현 횟수를 그대로 추천 점수로
사용하지 않고, 최근 회차의 **개별 번호 출현 빈도와 홀짝 패턴**을
기반으로 조합을 생성합니다. 10\~1000회 범위의 표본에서 동일 6번호 조합은
대부분 희소하기 때문에 이 방식이 화면 기능과 데이터 특성에 더
적합합니다.

또한 이 기능은 당첨 확률을 예측하거나 보장하지 않습니다. 과거 데이터
기반의 조합 생성 보조 기능입니다.

## 저장

`src/storage/recommendSettings.ts`에서 번호 생성 관련 저장 상태를
관리합니다.

-   내 번호: 최대 30개
-   필수 번호: 현재 저장값 1개
-   제외 번호: 현재 저장값 1개

React Native의 AsyncStorage를 사용합니다. 기존 프로젝트에 해당 의존성이
없다면 다음 패키지가 필요합니다.

``` bash
npx expo install @react-native-async-storage/async-storage
```

## JavaScript 참고

통계 집계와 정렬은 최신 ECMAScript/MDN의 `Array.prototype.map()`,
`Array.prototype.sort()`, `Map` 동작을 기준으로 작성했습니다. 숫자
정렬에는 비교 함수를 명시하고, 원본 배열 변경을 피하기 위해 복사 후
정렬하는 방식을 사용합니다.
